# 0006 Generated loader, a small loader.css, one style hash

Status: accepted.

The only HTML is generated by the gateway (`gateway/src/statics`). It loads `/assets/{public|app}/boot.js` and a very small `/assets/loader.css` (a background colour and a "Loading" line shown before the WASM starts). `boot.js` is generated by `scripts/build_wasm.sh`. It is not hand-written source.

Content Security Policy: `script-src 'self' 'wasm-unsafe-eval'`. `style-src 'self'` plus one exact hash with `'unsafe-hashes'`. The Iced web runtime sets one inline style value on its canvas (`display: block; width: 100%; height: 100%`) through `setAttribute`, which the browser blocks without that hash. The hash allows only that exact value. `'unsafe-inline'` is not used.
